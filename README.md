# WordPress Plugin Development

Course repository for WordPress plugin lessons.

## Branch strategy

Each lesson uses its **own branch**. Checkout the branch for the lesson you are on.

| Branch | Lesson |
|--------|--------|
| `Content` | Content / Custom Post Types (`topten-plugin`) |
| *(more branches as lessons are added)* | |

```bash
git clone https://github.com/mdhemalakanda/WordPress-Plugin-Development.git
cd WordPress-Plugin-Development
git checkout Content
```

Copy `topten-plugin/` into your local WordPress `wp-content/plugins/` folder and activate it.
